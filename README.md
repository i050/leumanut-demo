# לאומנות — דמו אתר

אתר סטטי בעברית וב־RTL. כולל בית, אטלס גאוגרפי, שישה עמודי אזור, אקטואליה, סדרות, עמודי צפייה מוטמעים, חיפוש, ארבעה ספרים וסל עם הזמנת דמו ללא פרטים אישיים או חיוב.

## הפעלה

מהתיקייה הראשית של הפרויקט:

```sh
node demo/serve.cjs
```

פתחו http://127.0.0.1:4173 . אפשר גם להגיש את תיקיית `demo/dist` בכל שרת קבצים סטטי. אין שלב build או dependencies. נדרש HTTP כדי לטעון את קובץ המפה.

## מבנה

- `index.html`: מעטפת האתר והניווט.
- `data.js`: התוכן המאומת, אזורים, שיוכים לדמו וספרים.
- `app.js`: ניתוב hash, מסכים, סינון, חיפוש וסל בזיכרון בלבד.
- `styles.css`: פריסה, טיפוגרפיה, RTL, מובייל ונגישות.
- `assets/`: עטיפות מקוריות, צילום היוצר ונתוני גבולות למפה.
- `assets/SOURCES.md`: מקורות וקרדיטים.

## גבולות הדמו

התכנים הם מבחר ערוך, לא פיד עדכונים חי. אין תאריכי פרסום או משכי וידאו שלא אומתו. הסל נשמר רק בזיכרון הדף ומתאפס ברענון. השלמת הזמנה היא סימולציה מקומית, ללא בקשת רשת או איסוף מידע. קישורי Bookpod מובילים לקטלוג המקורי.

YouTube והתמונות הממוזערות דורשים רשת. הנגן הוא נגן YouTube רשמי במצב privacy-enhanced; זמינותו תלויה ב־YouTube ובהרשאות הסרטון. גופנים נטענים מ־Google Fonts עם גופן מערכת כגיבוי. התמונות של הספרים והמפה מקומיות.

כל שיוך גאוגרפי הוא בחירה עריכתית לצורך הדמו. המפה מבוססת GeoJSON אמיתי אך אינה מפה מדינית עדכנית.

## כיוון חזותי

העיצוב המחודש נעשה בהשראת האתר שנבחר על ידי המשתמש: https://www.genesis.com/worldwide/en . ההשראה מתייחסת לפתיחה קולנועית, ניווט מצומצם, טיפוגרפיה נקייה ומדורים מרווחים. המיתוג, התוכן והנכסים הם של דמו לאומנות; לא נעשה שימוש בלוגו או בצילומי הרכב של Genesis.
